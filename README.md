# Download speed CLI

Тестовое задание: скачать ответ по заданному URL **10 раз последовательно**,
посчитать среднее время запроса, общий объём данных и скорость скачивания.

## Запуск

Нужен **Node.js 22 или новее**. Сторонних зависимостей нет, `npm install` не нужен.

```sh
node download-speed.mjs "https://example.org/large-image.jpg"
```

Замените пример на прямой URL доступного файла. Адрес с `&` и другими
специальными символами передавайте в кавычках. Альтернативный запуск:

```sh
npm start -- "https://example.org/large-image.jpg"
```

Результат: число успешных запросов, среднее время в миллисекундах, объём в
байтах и МиБ, суммарное время в секундах и скорость в **Мбит/с**.

Проверка:

```sh
npm test
```

Тесты запускают настоящий локальный HTTP-сервер и CLI отдельным процессом.
Внешний интернет, ключи и дополнительные пакеты для тестов не нужны.

## Как считается результат

Для каждого запроса время измеряется монотонными часами `performance.now()`:
от начала запроса до окончания чтения **всего тела ответа**, а не до заголовков.
Следующий запрос начинается только после завершения предыдущего.

```text
Среднее время (мс) = сумма длительностей 10 запросов / 10
Общий объём (байт) = сумма фактически полученных байтов тела всех ответов
Скорость (Мбит/с) = общий объём × 8 / (сумма длительностей / 1000) / 1 000 000
```

1 МиБ = 1 048 576 байт. 1 Мбит = 1 000 000 бит.
Скорость не усредняется по отдельным замерам: при разной длительности это
дало бы другое, некорректное для общего скачивания значение.

Тело читается потоком, без сохранения всего файла в память или на диск.
Размер берётся из полученных чанков, не из `Content-Length`, поэтому
работают и ответы с chunked transfer encoding.

## Ошибки и границы измерения

- Поддерживаются HTTP и HTTPS. URL с логином/паролем не принимаются.
- На один запрос установлен общий таймаут **30 секунд**, включая соединение
  и чтение тела; непрерывная медленная передача не отменяет этот предел.
- При HTTP-статусе вне 2xx, сетевой ошибке, обрыве тела или таймауте скрипт
  завершает работу с кодом 1 и номером неудачного запроса. Частичная серия
  не выдаётся за успешный замер из 10 запросов. Автоматических повторов нет.
- Автоматических редиректов нет: нужен конечный URL. Это сохраняет простой
  контракт — ровно 10 HTTP-запросов в успешном запуске, без скрытых переходов.
- Каждый запрос открывает отдельное соединение. В измеренное время входят
  соединение/TLS, ожидание сервера и передача тела. Паузы между вызовами и
  печать результата не входят.
- Запрашивается `Accept-Encoding: identity`; если сервер всё же пришлёт
  сжатый контент, считаются полученные байты без распаковки. HTTP-заголовки,
  служебные данные chunked framing и TCP/TLS overhead в объём не входят.
- Скрипт отправляет `Cache-Control: no-cache`, но поведение удалённого
  сервера/CDN не контролирует. Это пропускная способность скачивания
  **конкретного ресурса**, не гарантированная скорость тарифа провайдера.
- Один запуск скачивает файл десять раз: учитывайте размер файла и трафик.
